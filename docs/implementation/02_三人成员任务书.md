- 非作者审查，合并后在 `dev` 重跑最小烟测；把结果填入[验收记录](../milestones/停车场项目_里程碑验收记录.md)。**仅有 BUILD SUCCESS、页面可打开或 PR merged 都不等于业务验收。**

## 6. 最终“拿文档给 AI”怎么用

成员 1 给 AI：本文件第 0/1/4/5 节 + `00/01/03` + 实际仓库。成员 2：第 0/2/4/5 节 + 同样四份；成员 3：第 0/3/4/5 节 + 同样四份。把成员姓名、分支名和本次任务 ID 写在提示词末尾。AI 一次只实现一个 PR 范围，不同时要求“做完整项目”；这样在三个分支上互不抢改，也便于每步验收。
